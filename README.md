## Instalación e inicio

### Windows
Ejecutar:

start.bat

El script debe instalar dependencias si hacen falta y luego iniciar el proyecto.

### Linux / Ubuntu
Dar permisos la primera vez:

chmod +x start.sh

Luego ejecutar:

./start.sh

### Inicio manual

npm install
npm run dev

Luego abrir:

http://localhost:5173
